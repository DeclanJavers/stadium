# Real-world dimensions: UK training ground and stadium kit

Legend: [src] = found in a web search (source noted). [mem] = from memory, not verified in this pass, so check before use. "n/s" = not sourced. All lengths in mm unless stated. Where sources conflict, both values are given.

Older source gives L 4484, WB 2580 [src]. Tyres: front 540/65R24, rear 600/65R38 [src: TractorData 2025]. A 2022 listing gives front 380/85R28 for 4WD, which conflicts.
- John Deere X350 garden ride-on mower: Deere official: H 1171, L 2468, WB 1275, W 1112 with mower / 962 without [src: Deere]. TractorData: L 1820, WB 1250, W 960–1040, H 1090–1190 [src]. The two conflict, so check the mower-deck basis before use. Tyre size: n/s.
- Caterpillar 313 13 t crawler excavator: 313F GC transport L ~7700, W 2490 (2590 with 600 mm track), H 2830 (boom down), weight 13.3 t, track width 500 mm [src: lectura-specs]. 313D transport L 7610, W 2490, H 2830, ground clearance 430 [src]. 313D2 is 15.9 t, W 2680, H 3220 [src]. The 13 t class is the 313F/313D [src].
- Thwaites 6 t front-tip dumper: L 4475, W 2240, H 3430 (Thwaites MACH2265 spec sheet and hire listing) [src]. Used Mascus listings: L 4475 × H 3390 × W 2354, and one listing W 2135 [src]. Unladen weight 4270 kg [src]. Tyre size: n/s.
- Bomag BW 120 twin-drum (tandem) roller: L ~2530, W ~1270 operating (transport 1280), WB ~1750, drum width 1200, cab top ~2000 H [src: dealer listings]. Mascus lists transport 2470 × 1280 × 2470, but H = L looks suspicious, so check. Operating weight 2700–2750 kg [src]. Engine Kubota D1803, 25 kW [src]. The search result described the BW 120 AD-5 as a single drum with pneumatic tyres, which conflicts with the twin-drum description, so confirm the variant.
