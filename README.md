# Stadium Kit

Procedural, spec-accurate 3D assets for a customisable football stadium, from a Sunday league pitch
to a 150,000-seat bowl. Everything is generated by Python in Blender, exported as glTF with
**sockets** so the pieces snap together in any engine. Design: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Dimensions and shader maths: [docs/SPECS.md](docs/SPECS.md).

Requires Blender 5.1 (`/Applications/Blender.app`).

```bash
B=/Applications/Blender.app/Contents/MacOS/Blender

$B -b --factory-startup -P tests/run_tests.py                      # pitch-level tests
$B -b --factory-startup -P tests/test_stands.py                    # stand, seat and export tests
$B -b --factory-startup -P tests/test_roofs_lights.py              # roof, facade and floodlight tests
$B -b --factory-startup -P tests/test_signage.py                   # ads, carpets, screens, dugouts, tunnel
$B -b --factory-startup -P tests/test_game.py                      # game export, LODs, lights, Rust viewer
$B -b --factory-startup -P tools/build.py                          # every variant -> out/assets/*.glb + out/manifest.json
$B -b --factory-startup -P tools/review.py -- all --layout layouts/premier.json   # Cycles review renders -> out/review/
$B -b --factory-startup -P tools/export_stadium.py -- layouts/mega.json          # whole stadium (render quality) -> out/stadiums/*.glb
$B -b --factory-startup -P tools/export_stadium.py -- layouts/mega.json --game   # game-ready: baked PBR, LODs, lights -> *.game.glb
$B -b --factory-startup -P tools/preview_game.py -- out/stadiums/mega.game.glb  # what an engine receives, rendered on its own
$B -b --factory-startup -P tools/export_library.py                # asset library for the live editor
viewer/build.sh --offline && viewer/target/release/stadium-viewer layouts/premier.json   # live stadium editor (see viewer/README.md)
viewer/target/release/stadium-viewer out/stadiums/mega.game.glb   # real-time viewer for game exports
(cd viewer && cargo test --offline --release --workspace)          # Rust port parity + editor tests
```

Review shots: `broadcast`, `behind_goal`, `goalmouth`, `goal_side`, `grass_macro`, `corner_flag`,
`aerial`, `opposite`, `main_stand`, `stand_rows`, `exterior`, `seat_lineup`, `carpets`, `dugouts`, `screens`. Add `--night` for any shot
under floodlights (exposure compensates for the lux level, as a camera would).
The first Cycles run compiles GPU kernels (about 5 minutes); later shots take 10–45 s each.

## What exists

| family | variants | customisable |
|---|---|---|
| pitch | 7 grass types (`catalog/grass.json`) | size, height, 7 mowing patterns, stripe width/angle, wear, wetness, crown, line colour, hand-painted lines, optional marks |
| goal | `box`, `classic`, `portable` (`catalog/goals.json`) | frame colour, net colours, solid/bands/checker, hex/square mesh, mesh size, cord thickness |
| corner flag | `pro_spring`, `striped`, `grassroots` (`catalog/corner_flags.json`) | height, pole colours and bands, spring/rigid base, flag pattern and colours, wind |
| stands | 9 profiles from a 6-step rail terrace to a 4-tier 150k bowl (`catalog/stand_profiles.json`) | per side: profile, seat style, length; open or curved corners, corner radius, front gap, apron (turf/track/concrete), fascia and concrete colours |
| roofs | `modern_cantilever`, `full_translucent`, `membrane_cantilever`, `goalpost_classic`, `shed_cover` (`catalog/roofs.json`) | per side or stadium-wide: system, rise/slope, post spacing, translucent strip, sheeting, fascia and steel colours |
| facades | `concrete_frame`, `brick_heritage`, `metal_bands`, `glass_curtain`, `etfe_cushions`, `metal_fins` (`catalog/facades.json`) | per side: system, colours, night glow, stair cores, entrance spacing |
| floodlights | `roof_ribbon`, `corner_pylons`, `tube_pylons`, `grassroots_poles` (`catalog/floodlights.json`) | lux target, fixture type, colour temperature, mast type; `"lighting": "night"` in a layout turns them on |
| ads | 12 fictional brands (`catalog/brands.json`) | perimeter `led` / `static` / `none`, chosen sponsors, 3D carpets, LED ribbons per tier; every slot carries area + TV weight |
| screens | `ends`, `corners`, `center`, `stand_top` | size; scoreboard content (teams, score, clock, sponsor) |
| dugouts | `shell`, `box`, `shelter` | seats, seat style, colour; technical areas painted automatically |
| tunnel | `telescopic`, `portal` | colour, size |
| seats | `tipup_classic`, `bucket_fixed`, `bench`, `padded_vip`, `rail_seat`, `wooden_tipup` (`catalog/seats.json`) | colour patterns (solid, tiers, rows, bays, gradient, random mix), text/image mosaics, UV fade |

| layout | capacity |
|---|---|
| `sunday_league` | 802 (384 seated on benches, 418 standing) |
| `classic` (four separate stands, kop terrace) | 19,285 |
| `premier` (three-tier bowl) | 61,192 |
| `mega` (four-tier bowl) | 152,854 |

A stadium is one JSON file; see `layouts/`. Grass types carry starting gameplay values (ball roll,
bounce, traction, wear rate, climate range) for the match engine to calibrate.

## Layout

```
kit/core/      scene, mesh (numpy geometry), nodes (shader builder), materials, sockets, render, export
kit/assets/    pitch.py, goal.py, corner_flag.py, seat.py, stand.py, roof.py, facade.py, floodlight.py,
               ads.py, screen.py, dugout.py, tunnel.py
kit/ads/       studio.py (creative rendering), placement.py (boards, carpets, TV weight)
kit/stands/    sightlines.py, geometry.py, patterns.py, roofs.py, facades.py, floodlights.py
               (pure numpy: the runtime generators the game can port)
kit/assembler.py   layout JSON -> scene, by snapping assets onto sockets
catalog/       variant presets (data, shared with the game)
layouts/       example stadiums
kit/core/game.py, bake.py   game export: baked PBR, tint split, metric UVs, light conversion
tools/         build.py, review.py, export_stadium.py, preview_game.py, export_library.py, dump_reference.py
tests/         run_tests.py, test_stands.py, test_roofs_lights.py, test_signage.py, test_game.py
viewer/        Rust (wgpu/Metal, egui) live stadium editor and viewer for game exports
viewer/gen/    Rust port of the generators (crate stadium-gen) with parity tests against the Python
```
